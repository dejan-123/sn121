# Prep examples

These cases are invented. Keep the checks and ordering; never reuse the names, facts, figures or sentences.

## Fast calls

- Four draft topics produce four numbered entries, each with that topic's exact `filed:` text. An uncovered open row becomes one extra `filed: not on the draft` entry.
- `DONE + IN PROGRESS + OVERDUE + DONE` is `2 of 4 supplied rows done (50%)`. Manager rows count in the denominator, and a manager `DONE` row is not still owed.
- `planned to escalate` stays conditional. Ask whether it happened; do not write that it did.
- An assigned reviewer queue is a routing or capacity decision. The manager owns the fix; the report is not the personal blocker.
- If the report already named the cause of a miss, coach the earlier flag rather than repeating the miss.
- A justified public objection keeps its substance. One narrow channel question is the maximum.
- A bare draft still gets a sheet. A record of a meeting already held gets only the redirect.

## Worked input

The manager is preparing for Owen Price, Returns Operations Specialist. Draft topics: `Recognition for the warehouse map fix`; `Coaching on impatient tone with Inventory`; `Status on label migration`; `Check on cross-training`.

Action rows: Owen, warehouse map update, `DONE`; Owen, label migration checklist, `IN PROGRESS`; Manager, approve label-printer access request, `OVERDUE`; Manager, confirm cross-training nomination, `DONE`.

Signals: Priya Rao, Operations Manager, wrote Monday that Owen's warehouse map fix prevented a mispick during the regional surge. Tuesday Owen told Inventory in #returns-ops: “Please stop sending labels without lot IDs; three shipments failed validation.” Wednesday the label migration was waiting on the manager's printer-access approval. Owen submitted: “Could cross-training lead toward the returns lead role?” Figures: 18 of 24 label checks passed; failed supplier labels rose from 4 to 7.

## The sheet it earns

# Owen Price, Returns Operations Specialist: named credit and one manager-owned approval

**Week at a glance.** Owen's warehouse map fix received named credit after it prevented a mispick during the regional surge. Label migration is still in progress and waiting on the manager's overdue printer-access approval. The Inventory message concerns missing lot IDs in supplier labels rather than a pattern in Owen's conduct. Action items: 2 of 4 supplied rows done (50%). Label checks: 18 of 24 passed (75%); failed supplier labels moved from 4 to 7 (+3 on a base of 4).

**Manager handles first.**
- Printer-access approval: OVERDUE; decide it or give the date before asking Owen for the migration next step.
- Fetch the label specification or Inventory intake rule.

## Conversation plan

**1. Credit — warehouse map fix (~4 min)**
filed: “Recognition for the warehouse map fix” → credit: Priya tied the fix to preventing a mispick.
Open with Priya's named credit and the surge outcome. Keep it specific to the map fix.

**2. Unblock — Inventory labels without lot IDs (~6 min)**
filed: “Coaching on impatient tone with Inventory” → re-routed: one justified objection about missing fields, not a conduct pattern.
Confirm the required lot-ID rule and who owns it with Inventory. If channel still matters, ask only one narrow question; otherwise leave it out.

**3. Unblock — label migration approval (~6 min)**
filed: “Status on label migration” → unblock: migration is in progress but waiting on your printer-access approval.
Settle the approval or name the date, then ask what remains once access clears.

**4. Career — cross-training toward returns lead (~10 min)**
filed: “Check on cross-training” → career: Owen submitted the path himself.
Ask which parts of the map fix or migration evidence the lead role, and what cross-training should add next.

**5. Holding — label migration checklist (~4 min)**
filed: not on the draft → holding: Owen's checklist row is IN PROGRESS but no draft topic covers it.
Ask what remains and whether it depends on the same access approval.

## Route elsewhere

Nothing requires another venue.

**Why this order.** Priya's named praise earns the opener. The Inventory item moves out of coaching because the supplied objection concerns missing label fields, not repeated behaviour. The overdue access approval is the manager's work to clear, and the unfiled checklist stays visible rather than disappearing.

## Sparse and old-record reminders

For a bare future draft, say which records never arrived, keep every topic numbered, ask grounded questions and fetch each missing record separately.

For a held meeting, use `# <name>, <role>: not a 1-on-1 prep request`, stay under 180 words and send no sheet. List open actions with exact owner and due date, state that current status is absent, and ask for action status, fresh signals, a report topic and a new draft agenda.
