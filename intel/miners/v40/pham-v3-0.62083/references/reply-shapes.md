## Where this request belongs

A role-family benchmark checks existing bands against an outside pool that has already been gathered and classified. None of these asks is that:
- **Whether the CFO's package suits a Series B company**: executive pay is set by the board with its own comparator group.
- **A starting salary for one applicant**: an individual offer is decided inside the band, case by case.
- **What warehouse leads earn in Antwerp**: no pool came with the request, and figures from memory could not be sourced.

Send the band per role family and level and the classified outside points (source, type, date, location, funding round, figure); the benchmark returns a verdict, its funnel and a confidence tier per family.
