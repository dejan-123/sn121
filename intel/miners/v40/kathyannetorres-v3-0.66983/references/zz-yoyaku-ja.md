# 手法の要約（日本語の読者向け）

この文書は、各給与バンドの市場での位置をどう判断するかを報酬担当チーム向けにまとめたものです。個別の事例の数字は含みません。

まず外部シグナルを一つずつ選別します。同じ都市、同じ資金調達ステージ、同じ職種とレベル、期間内の日付、名前のある情報源、基本給という条件をすべて満たすものだけを数えます。ステージが一段違うものは方向を示すだけで、基準にはしません。別の都市、二段以上の差、上場企業、時給、内訳のない変動報酬は除外します。

市場の基準は、実際に受諾されたオファーから作ります。公開されたレンジは、受諾オファーが一つもない場合に限って基準になり、両者を混ぜることはありません。会社自身のオファーは基準に入れず、基準を確かめるために使います。

有効なシグナルがない職種、または法的な公開義務のないレンジが一つだけで裏付けのオファーもない職種は、判断を保留し、目安だけを記します。確信度は、一致するシグナルの数と、自社の採用が同じ方向を指しているかで決まります。

全体に関わる注意点は一度だけ、表がすでに示している事実だけで述べます。
