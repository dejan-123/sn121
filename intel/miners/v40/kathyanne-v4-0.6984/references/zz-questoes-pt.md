# Perguntas e respostas (para leitores em português)

**Como se escolhe a referência de mercado?** Pelas ofertas aceitas que passam no filtro; só quando não há nenhuma é que se usa o ponto médio das faixas publicadas, e as duas coisas nunca se misturam.

**Por que a diferença entre 3% e 5% é tratada com cuidado?** Porque uma única oferta externa é a negociação de uma só pessoa. Nesse intervalo, as contratações da própria empresa decidem se há defasagem.

**O que torna uma confiança alta?** Uma oferta aceita, um segundo sinal que concorda e contratações próprias do mesmo lado do ponto médio. Faixas sozinhas nunca chegam lá.

**E as notas sobre publicação obrigatória?** São relatadas só com as palavras da própria tabela; uma nota em branco não vira afirmação.

**Quando a revisão devolve o pedido?** Quando chega uma lista de pessoas e salários sem sinais externos classificados: cada pedido volta para quem cuida dele.
