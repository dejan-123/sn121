## What to do now

Now the real request. Write its working sheet as plain text, in full, in the form above: the pool line listing every ID and the first month in window copied from the input; the own-offers line, each family's offer line copied from the input and every offer written out ("two at X and one at Y" is X; X; Y); then for every family its points one per line with their tests (a partial point's figure or midpoint set against the band midpoint in numbers); then the Counts, Deferral test (with its three questions when one posted range is the only full point), Reference with the signed gap, Row (which row of the verdict table, decided before own offers), Own reading, Verdict and Tier lines; then the totals block as above, with the window slots, mandate-note, source and snapshot-gap lines. End the sheet with the line "Totals checked; the document is next." and, in that same message, call read_reference for `references/document.md`. The document is written only after that call returns.
