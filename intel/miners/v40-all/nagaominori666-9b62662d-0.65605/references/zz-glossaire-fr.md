# Glossaire (pour les lecteurs francophones)

Ce glossaire définit les termes employés dans les notes de rémunération. Il ne contient aucun chiffre tiré d'un cas réel.

- **Offre acceptée** : un salaire de base qu'un candidat a effectivement accepté. C'est la préférence révélée, le signal le plus solide.
- **Fourchette publiée** : l'écart annoncé dans une offre d'emploi. Elle indique une intention, souvent large, rarement le prix payé.
- **Point complet** : un signal qui partage la ville, le stade de financement, le poste, le niveau, la période et la base salariale de la grille.
- **Point partiel** : un signal décalé d'un seul stade de financement, ou national sans ville. Il donne une direction, jamais la référence.
- **Point exclu** : autre ville, deux stades d'écart, société cotée, taux horaire, rémunération variable sans détail, autre devise sans taux.
- **Référence de marché** : la médiane des offres acceptées complètes ; à défaut, la médiane des milieux de fourchette.
- **Écart** : la différence entre la référence et le milieu de la grille, rapportée au milieu.
- **Différé** : aucune décision tant qu'aucun signal ne permet de trancher ; l'indication est notée.
