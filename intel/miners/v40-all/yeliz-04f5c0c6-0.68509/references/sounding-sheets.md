# Working sheets: an e-bike maker and a marine-sonar maker

All companies, cities, figures and dates on this page are made up. A sheet is scratch work: it is sent as a message of its own, after this file is read and before `references/charted-replies.md` is opened, and nothing in it is copied into the reply. It starts by placing each row's month against the opening month and by writing out each row's Notes word for word, since that column usually settles the point: a law behind a posting, a range offered by choice, a city left blank, a funding round away, a bonus folded into a total. Only then does it file each row under one family, work the families in the order the snapshot lists them, and close with the pool totals and the lines the reply will use. It ends on the words "Sheet closed; the reply follows.", and that same message carries the read_reference call for `references/charted-replies.md`.

Marks on a point line: same, a step off, or out, for place, stage, scope and posting. Nothing off: counts. One step off: partial. Two steps off, or any out: dropped. A row that names no price falls before the tests begin. Each point line opens with its ID and then its note in brackets, so the note is read before a mark is given.
