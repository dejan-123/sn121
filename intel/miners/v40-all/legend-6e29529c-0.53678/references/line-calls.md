# Line calls - the hard single boundary calls, as a quick check before I write

Invented one-liners, stated as judgment. Each is a point that looks like one thing and is read as another. I take the discipline, never the numbers.

## Which fit, and when it drops

- A reworded or bundled title that plainly names the same role at the same level ("Senior Platform Engineer, also owns the build pipeline") is scope Full - the duties map to the level, not a mismatch.
- A posting one cost tier over from the internal anchor, or in a nearby smaller metro, is geo Partial - it still counts, at capped confidence.
- A remote-national figure against a metro-anchored internal role is geo Partial, never Full.
- A coastal tier-1 metro against an inland tier-2 one is geo Incomparable - set aside; admitting it inflates the market centre.
- One funding stage apart is stage Partial; two or more apart, or a public company against a private one, is stage Incomparable - set aside.
- A figure in another currency with a supplied rate is usable; with no rate it is Incomparable - set aside, never invent a rate.

## The type ceiling

- An accepted offer is revealed pay: full weight.
- A posted range is an aspiration: admissible, but it caps the family at Low confidence.
- A recruiter-reported or verbally-shared figure is hearsay - too weak to carry a verdict, set aside.
- A survey median with no date or no methodology is too thin - set aside; a dated, method-stated survey can corroborate but never lead.

## What the figure itself cannot carry

- Retention grant, sign-on bonus, acquisition or merger package: no isolable base - set aside.
- An accepted figure given as a package "including an unspecified sign-on": recurring base cannot be separated - set aside, do not guess the split.
- Equity-heavy or cash-heavy total comp with no stated base: set aside.
- An OTE with no base split: set aside; I do not back into a base from a target.
- A contractor or hourly rate: non-FTE - set aside, never annualised.

## The call, right at the boundary

- Accepted offers clearing band max -> Lagging. Two offers at 186k and 189k against a 178k max: the band cannot reach the market, whatever the postings say.
- A decline flips a within-band read to Lagging. If every surviving range centre sits in band but a candidate declined band-level pay citing higher competing comp, the band does not hold people - weigh the decline before the ranges.
- A within-band posting alone is never Lagging. One range whose top merely pokes past max, with no accepted offer and no decline, is Competitive at Low - a posting is an aspiration, not revealed pay.
- Market centre below band min -> Above-market. Call it only when the surviving centre is genuinely under the floor, not merely low in band.
- A market figure a few points above an internal offer, both in band, stays Competitive. A small in-band gap is not lagging.

## How sure, and the one refusal to call

- Two or more fully-comparable accepted offers that agree -> High.
- One fully-comparable accepted offer -> Medium.
- Only posted ranges survive, or the call leans on a lone accepted offer that is a one-dimension partial -> Low.
- A single fully-comparable posted range is a Low call, not a hold.
- A surviving accepted offer anchors a call even as a one-dimension partial: an adjacent-metro or one-stage-off accepted offer gives a Competitive/Low or Lagging/Low call, naming the soft fit - it does not hold.
- Hold only when nothing can anchor a call: the survivors are conflicting posted-range partials, everything lands two or more fits off, or nothing maps to the family. Name the exact gap and the one figure that would close it.

## Conversions, written out

- Total comp with a stated bonus: "191,000 total - 27,000 bonus = 164,000 base (down)" - I compare 164k, not 191k.
- OTE with no base split: "210-250k OTE, no base split: cannot isolate base, set aside, not guessed."
- Foreign currency, no rate: "EUR 138,000, no rate supplied: set aside, no invented rate."

## The funnel has to add up

For each family: screened = the distinct IDs I mapped there; counted IDs (fully comparable or one-dimension partial) plus set-aside IDs equal screened; every set-aside reason names its ID; a reason the family's points did not earn - out of window, weak source, non-FTE - never appears in its funnel. The Read line names the surviving figure and the ID behind the call, never a point I set aside.
