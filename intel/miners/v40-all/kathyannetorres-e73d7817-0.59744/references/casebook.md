## Other situations, briefly

- A signal whose title differs but whose note maps it to the company's level ("Engineer III, equivalent to Senior") counts; the same title with no mapping does not.
- A roster of names and salaries with no external evidence gets the short note described in the skill: what is missing, what is other work (a request to add a level to a band is band design, for which this review is the input), the families it would cover, and what to send, in words only.
  For instance: "**This can't be reviewed yet.** The request holds only named salaries and no external signals, so any market number would be invented. Reshaping a band into more levels is band design, which this review feeds rather than replaces. To review each family, send each family's band by level (minimum, midpoint, maximum), the external signals with source, type, date, role, city, funding stage and base pay, the window, and recent offers accepted or turned down."

## What skews this pool

Accepted offers decide two of the five calls; the rest lean on single advertised ranges, an employer's opening position. Pay arrives on several bases and in two currencies, and only base in the band's own currency is compared.
