# Scope note: Brackenridge Freight Tech

Both asks are real, and neither is a band benchmark, so there is no table here.

The support-staff comparison is a pay-equity audit. It compares your own people with each other, and counsel should direct it so the work stays privileged; market evidence plays no part. Whether to match the competing offer is a decision about one engineer. It turns on that person's level, record and the cost of losing them, and it belongs with the manager and whoever owns pay; a market table cannot make it, and I would be guessing from an export.

Behind the second ask sits a question I can answer: does the data engineering band as a whole trail the market? That needs two things you have not sent: outside pay evidence for data engineers, each point classified the way an evidence table would be (where it came from, what kind of figure, when, which city and company stage), and the band itself by level. Thursday is close, so the useful step today is an intake sheet for that family; I can draft it now, and it commits you to no pay judgement.
