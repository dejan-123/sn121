# Manual evaluation prompts

1. For each scenario, open a fresh chat and paste the `*-generate.md` file.
2. Copy the model's response into `<PASTE THE GENERATED RESPONSE HERE>` in the matching `*-judge.md` file.
3. Paste that judge prompt into a second fresh chat and collect the score.

These prompts make no API calls. They are useful for style and contract checks, but cannot reproduce the sealed scenario judge notes or guarantee the platform score.
