# Manual evaluation prompts

Generated by `tools/export_eval_prompt.py`. The default output path is
`manual-evals/<vNN>/<bundle>/`. Each versioned directory contains:

- `S-###-generate.md` — paste into Claude/ChatGPT to produce a response;
- `S-###-judge.md` — paste the generated response into the marked slot for a
  public-rubric review.

These prompts make no API calls and cannot reproduce sealed `scenario_quality`
criteria or official `skill_use` judgments.

Current archives:

- `v38/scout-plain-v1/` — exported prompts for the final v38 bundle.
