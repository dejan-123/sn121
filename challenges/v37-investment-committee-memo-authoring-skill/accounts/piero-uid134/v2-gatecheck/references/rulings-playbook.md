# Gate rulings — the quick playbook

A ruling sheet consulted when a situation is uncertain: match the
row to the closest situation, take the ruling, write it in the
worked memo's shape. These are precedents, not the contract — the
contract lives in SKILL.md.

## Filed statuses

| The situation | The ruling |
|---|---|
| Contract marked `Resolved` whose own text says the re-bid still runs | reads open; the cell names the live re-bid as the tiebreaker |
| Consent marked `Resolved` that no artifact documents | reads open; the signed consent is the named record |
| Review marked `Resolved` that was deferred, not closed | reads open; deferral is not closure |
| A consent right that persists by nature — the licence will always need one, the customer can always cancel | `Resolved` may stand; the proving document becomes a closing deliverable |
| A status cell left blank | reads open; the memo says the cell was empty |
| A serious risk filed honestly at a live status | stands as filed with its mitigation — restraint needs no `Resolved` |
| An analyst note flagging a table-versus-narrative conflict | carried and shown; the memo names which side it trusted |

## The priced base

| The situation | The ruling |
|---|---|
| One-time revenue inside the quoted base | stripped before any multiple is quoted |
| Revenue that does not transfer — a grant a for-profit cannot hold, a contract that terminates, a customer already gone | excluded; the surviving base is what prices |
| An industry that prices on net revenue | the net figure is the base; the memo says why gross is not |
| A churn-out cohort shrinking the run-rate | the run-rate is a second priced base; the ask's implied multiple is written on each |
| EBITDA-negative base, or a pre-profit comp set | EV/EBITDA named not meaningful; EV/Revenue carries |
| An add-back that recurs every year | rejected in words; never subtracted twice |
| Growth quoted off unsigned prospects or unconverted pilots | a claim, not the priced rate |

## Comparables

| The situation | The ruling |
|---|---|
| A comp acquired at a control or sponsor premium | excluded, in the note's own words |
| Growth or margin that prices a different business | excluded, direction named |
| An NM multiple on the metric in use | excluded |
| A set note declaring a limit — mix undisclosed, one viable multiple | the limit is carried into the memo, never worked around |

## The call

| The situation | The ruling |
|---|---|
| Every must-address settled; a manageable row still open | proceed — the open row takes a named mitigation |
| Open must-address rows, each answerable by a document | request more data — the record and its issuer are named |
| A counterparty on record refusing | pass |
| A term or rule that bars the transfer the thesis prices | pass — the surviving base is recomputed and shown |
| The clearing record cannot exist on the timeline — live adjudication on the priced asset, an expired right | pass; the memo names what would reopen the file |
| A permission still pending — application filed, approval not yet granted | askable, not a bar; a bar is a rule already on the books |
| An ask above the range | a price condition — repriced, never declined on price alone |
| A clean file | proceed — holding back is as wrong as proceeding over an open must-address |

## Instruments

| The need | The instrument |
|---|---|
| A document a named party can issue | closing deliverable |
| A bounded liability | specific indemnity or escrow |
| Revenue whose survival waits on a post-close event | contingent consideration |
| A quantified, unfunded need | price reduction |
| People the value walks out with | retention or non-compete |

Timing is one of four marks — before LOI, before signing, at close,
post-close. Never an invented period, percentage, escrow size or
earnout; a condition never predicts what the document will say.
