# Examination notes — how recurring questions get answered

The questions below come up in nearly every file. Each carries the
answer the record supports — match the situation, take the answer,
write it in the worked memo's shape.

## Status questions

- "The row says Resolved — is it?" Only if the record confirms it.
  A re-bid still running, a deferred review, an undocumented
  consent, a claim the row itself calls pending — each answers
  open or blocks, with the fact that broke the label quoted.
- "A consent the deal will always need — is that unresolved?" No.
  An exposure that persists by nature can hold `Resolved` in the
  analyst's sense; the proving document becomes a closing ask.
- "The cell is empty — what filed?" Nothing. An empty status
  answers open, and the memo says the cell was empty.
- "The analyst note contradicts the table — which wins?" Neither is
  smoothed. The memo carries the conflict and names the side it
  trusted.

## Base questions

- "What of this revenue recurs?" Everything except what completed
  and will not return — one-time projects strip first.
- "What of this transfers?" Only what the buyer can hold: not
  grants a for-profit cannot keep, not terminable contracts, not
  customers already gone.
- "Which denominator does the industry use?" Where the standard is
  net revenue, gross is the seller's framing, not the base.
- "Is EBITDA meaningful here?" Only on the economics that transfer.
  A negative base or a pre-profit comp set answers EV/Revenue.
- "Is this add-back real?" Only if it is genuinely non-recurring.
  Evergreen costume is rejected in words — never subtracted twice.
- "Whose growth prices?" Realized growth. Unsigned prospects and
  unconverted pilots answer "claim."

## Comp questions

- "Does the premium-priced comp belong?" No — a control or sponsor
  premium is a transaction price, not a market multiple.
- "Does the outlier belong?" Not when its growth or margin prices a
  different business.
- "What about the NM multiple?" Excluded.
- "The set's own note admits a limit?" Carry the limit into the
  answer — never price around it.

## Answer questions

- "Every gating question answered, one manageable open?" Proceed —
  the open question takes a named answer in the asks.
- "Open gating questions a document can answer?" Request more data
  — the record and its issuing party are named.
- "A counterparty on record refusing?" Pass.
- "A rule that bars the transfer itself?" Pass — the surviving base
  is recomputed and shown.
- "The only clearing record cannot exist on this timeline — live
  adjudication on the priced asset, an expired right?" Pass, and
  name what would reopen the question.
- "A permission still pending?" Askable — a bar is a rule already
  on the books, not a decision still pending.
- "The ask sits above the range?" A price condition — repriced,
  never declined on price alone.
- "Nothing blocks?" Proceed — declining to answer a clean set is as
  wrong as proceeding over a blocking question.

## Ask questions — instruments

- A document a named party can give → closing deliverable.
- A bounded liability → specific indemnity or escrow.
- Revenue whose survival waits on a post-close event → contingent
  consideration.
- A quantified, unfunded need → price reduction.
- People the answer walks out with → retention or non-compete.

Timing answers from four marks — before LOI, before signing, at
close, post-close. Never an invented period, percentage, escrow
size or earnout; an ask never predicts what the document will say.
