# From the tab desk — the clerk's running list

Things the clerk checks while the binder builds:

[ ] every row read twice — once for the label, once for the
    evidence behind it
[ ] blocking count stated in words, not implied
[ ] the seller's number never enters the range without the
    bridge beside it
[ ] each comp kept or returned, reason written, no silent rows
[ ] both range products split and shown — whole and decimal
    parts
[ ] enterprise to equity: the debt bridge gets its line, or the
    gap is marked to confirm
[ ] the ask restated on the corrected base, gap in money and
    percent
[ ] instruments matched: signable paper → precedent; bounded
    liability → indemnity; event-bound revenue → contingency;
    quantified gap → price item; key people → retention
[ ] nothing sized, dated or named that the artifacts did not
    give
[ ] resolution on line one; same resolution in section four
[ ] no tab vocabulary inside the summary — the summary reads
    as a memo
[ ] the checklist is the last section, and the requests are the
    last items on it
