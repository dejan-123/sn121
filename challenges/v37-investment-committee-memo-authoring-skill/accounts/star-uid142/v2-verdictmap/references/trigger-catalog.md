# Trigger catalog — the states that decide deals

A catalog of triggers that show up in nearly every map, with the
state each arms. When a row sits between readings, find its entry
here and map the same way.

## Status triggers

| Trigger | Maps |
|---|---|
| Filed `Resolved`, but the record shows the closing event never happened — a re-bid live, a review deferred, a consent never documented, a claim the row calls pending | triggered (gating tier) or pending with the reason quoted (manageable tier) |
| Filed `Resolved` beside an exposure that persists by nature — a consent the licence always needs, a right to cancel | clear — the proving document maps to a closing deliverable |
| A status cell left blank | pending, and the memo says the cell was empty |
| A serious risk filed honestly at a live status | pending with its disposition — restraint needs no `Resolved` |
| An appended analyst note flagging a table-versus-narrative conflict | maps as evidence, never smoothed — the memo names the side it trusted |

## Base triggers

| Trigger | Maps |
|---|---|
| One-time revenue inside the quoted base | mapped out before any multiple |
| Revenue that does not transfer — a grant a for-profit cannot hold, a terminable contract, a departed customer | excluded; the surviving base is what prices |
| An industry that prices on net | the net figure is the base; gross maps as the rejected denominator |
| A churn-out cohort shrinking the run-rate | a second priced base; the ask's implied multiple maps on each |
| EBITDA-negative base or pre-profit comps | EBITDA trigger maps void; EV/Revenue carries |
| A recurring item dressed as an add-back | rejected in words; never subtracted twice |
| Growth off unsigned prospects or unconverted pilots | a claim; realized growth maps |

## Comp triggers

| Trigger | Maps |
|---|---|
| Acquired at a control or sponsor premium | excluded, in the note's own words |
| Growth or margin pricing a different business | excluded, direction named |
| An NM multiple on the metric in use | excluded |
| A set note declaring a limit | the limit maps into the memo |

## Verdict triggers

| Trigger | Verdict |
|---|---|
| No gating trigger armed; pendings carry dispositions | proceed — firing nothing on a clean map is right, not timid |
| Armed gating triggers, each clearable by a named record | request more data — record and issuing party named |
| A counterparty on record refusing | pass |
| A term or rule that bars the transfer itself | pass — the surviving base recomputes and shows |
| The clearing record cannot exist on the timeline — live adjudication on the priced asset, an expired right | pass; name what would rearm the map |
| A permission still pending | requestable, never a bar |
| An ask above the range | a price condition — repriced, never declined on price |
| Revenue that may not survive post-close | a base question, never a bar |

## Disposition triggers — instruments

| The need | The instrument |
|---|---|
| A document a named party can issue | closing deliverable |
| A bounded liability | specific indemnity or escrow |
| Revenue whose survival waits on a post-close event | contingent consideration |
| A quantified, unfunded need | price reduction |
| People the value walks out with | retention or non-compete |

Timing maps from four marks — before LOI, before signing, at close,
post-close. Never an invented period, percentage, escrow size or
earnout; a trigger never predicts what the document will say.
