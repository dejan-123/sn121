# Signal lexicon — pattern to tier, at speed

One line per pattern; the arrow gives the tier and the action. Use with the taxonomy and the two worked pools. Invented phrasings — match the shape, not the words.

## Elevation routes

- `unsearched register of the kind a term turns on` → must-address; the action is the search. Two terms on one search → lettered split.
- `unsearched register of another kind` → deeper-diligence; an observations archive is not the accreditation record, warning letters are not the enforcement list.
- `target spelled exactly + breach process under way (inspection, draft notice, regulator's own review) + pool unanswered` → must-address; action = written confirmation from the record-holder; a denial does not disarm it.
- `one fact, thin rows` — press + target release + tied party reporting the same established thing → must-address together, "read with row N", each keeping its action; missing implied count → "not yet measurable" + name the register.
- `attributed + corroborated or primary-binding + decisive for a stated term + before the step` → must-address.

## Held at deeper-diligence

- `name a letter, suffix or legal form off — even "(sic)"` → deeper-diligence; an identity question, never elevated; only a register joins two names.
- `target's own word on what the value rests on; unconfirmed win or renewal` → deeper-diligence; ask the counterparty for the papers.
- `searched-clean register answering a stated term` → deeper-diligence; dated comfort, re-read before the step.
- `certificate whose issuer another row doubts` → deeper-diligence; the finding rides the issuer's row.
- `claim ended for good on ground the deal stakes` → deeper-diligence; obtain the order and terms.
- `dismissal without prejudice off any stated term` → deeper-diligence; paused, able to return — and must-address where a term demands no active challenge.
- `departure or hire in the function a term or the thesis runs through, succession unnamed or unconfirmed` → deeper-diligence, even anonymous.
- `talks, approaches, in-discussions about a person a term names` → deeper-diligence; private chatter is not the breach process.
- `party-held facts` → deeper-diligence; requested through the deal channel, never searched for.

## Kept at monitor

- `independent record already confirms it` — counterparty filing, live register entry supporting the thesis → monitor; file it and move.
- `bare denial` → monitor; it never lifts the claim it answers.
- `counsel retention` → monitor; instructing lawyers is not a fact.
- `trade-body membership` → monitor; the body's good-standing list is not the regulator's view.
- `orderly succession, successor named and effective` → monitor.
- `claim dismissed with prejudice off the staked ground` → monitor; ended for good, cannot return.
- `filed figure clearing its threshold` → monitor; stands as filed, tested once.

## Noise

- `names nobody in the deal` → noise however grave, even when the event is the very one a walk-away guards against; the overlap is why the sweep returned it.
- `bears on nothing staked` → noise.

## Never the top tier

A near-match even when "referred for review" or the term covers breaches "regardless of size"; papers only the parties hold; a nobody-row; a searched-empty sweep; a register in hand showing the term met; a hire no term turns on; a claim already ended; a report of private talks. With no terms stated, only a live adverse claim on the thesis asset on an independent record reaches the top.
