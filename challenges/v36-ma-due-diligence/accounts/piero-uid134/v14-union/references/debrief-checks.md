# Debrief checks — count arithmetic and self-audit

Run this checklist against the draft reply before sending. Each item names the failure it catches.

## Row accounting

- Row total = numbered signals + lettered splits. A signal split into 4a–4d adds three rows; two signals split adds their extras each. Write the count line as `<rows> rows from <signals> signals (signal N split into Na, Nb…)`, then read down the tier column and sum: the four tier counts must add to the row total, not the signal total.
- Every numbered signal owns exactly one base row; absences sit where the input placed them. A second source inside one signal stays on that signal's row and never earns its own number.
- The tier cell carries only the four tier words — never "unsearched", "thin-report", "near-match" or a verdict phrase. The route a row took belongs in the bears-on or action cell.
- "Read with row N" is a cross-reference, not a merge: both rows keep their number, their tier and their own action. "Confirmed by row N" points backwards; "read with" marks one shared finding.

## Worked arithmetic examples

- 8 signals, one split into 3a/3b → 9 rows. Must-address rows 2, 3a (2); deeper-diligence 1, 4, 5 (3); monitor 3b, 6, 7 (3); noise 8 (1): `9 rows from 8 signals (signal 3 split into 3a, 3b). Must-address: rows 2, 3a (2) · Deeper-diligence: rows 1, 4, 5 (3) · Monitor: rows 3b, 6, 7 (3) · Noise: row 8 (1) · 2 + 3 + 3 + 1 = 9.`
- 7 signals, no splits, no must-address → `7 rows from 7 signals. Must-address: none (0) · Deeper-diligence: rows 2, 5 (2) · Monitor: rows 1, 3, 4, 6 (4) · Noise: row 7 (1) · 0 + 2 + 4 + 1 = 7.` A zero tier is still named with its count.
- 11 signals, two splits (10a/10b and 4a/4b/4c) → 14 rows; the count line names both splits before reading tiers.

## Before sending

- Heading opens with `## ` and nothing precedes it; anchor lines are labelled before the table.
- Each must-address row names which route earned it — decisive register, tripwire, shared finding or the four-part test — inside its action or the cross-signal check.
- Every dramatic row that stayed low appears in the elevation rationale with the test it failed; the closest row is named whether or not any row reached the top.
- The action cells name a role, a verb, the record or party and the step — no two rows share a sentence.
- Reply stays under 7,000 characters; nothing recommends go or no-go; no numeric score appears anywhere.
