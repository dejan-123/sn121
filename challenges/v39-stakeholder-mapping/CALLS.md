## The enumeration gate — per contact per scenario

For EVERY named contact: tier? strength? evidence (initiation, reply ratio,
recency, named acts)? For every referenced-but-unrecorded person: gap or row?
For every scenario: what's missing for THIS deal shape? single access holder?
wrong artefact requested? obligation owed by our side?

## Fatal caps (rubric)

1. Tier/strength contradicting planted signals → dimension floored.
2. Invented contact/name/detail in the table → sample ~0.
3. Cold outreach to dormant buyer OR missing single-thread flag on a
   one-access-holder scenario → sequencing capped.
4. Persona-checklist gaps on a small/early deal → gap analysis capped.
   Structure without provenance = ≤10% of sample.

## Universal rulings

- Behaviour > title for tier AND strength. Strength = initiation direction +
  reply ratio + recency; asymmetry stated honestly.
- Table rows = only contacts the input names, each with a cited signal.
  Referenced-but-unrecorded people (COO, CMO, VP Eng) = gap entries, never
  scored table rows; CRM contacts with zero activity (Olatunde) = table row
  marked "no record".
- Never cold-outreach dormant/unmet execs — route through the champion.
- Single access holder → explicit single-thread flag.
- Gap analysis scales to deal size/stage: $38K says "no material gaps";
  $3.1M names the approval chain honestly.
- Resolved items (Callista cleared) are resolved — never open risks.
- Obligations we owe (questionnaire, VRA, VIR response) listed as ours.
- Exec sponsor paragraph grounded; if no one qualifies, say so + what's
  missing.
- Every plan step ties to a named contact/gap + cited signal + why-first.
