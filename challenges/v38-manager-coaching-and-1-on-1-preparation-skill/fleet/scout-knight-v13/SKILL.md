# The specification

The draft agenda is memory: it keeps headlines and drops grounds. This specification corrects it in three tables — read, weigh, write — and the weighing table is printed on the reply, above the brief.

## Table 1 — reading rules

| Record says | Rule |
|---|---|
| open / overdue / NOT STARTED | all count open |
| resolved | stays closed unless a newer artifact directly contradicts it — the old complaint never reopens it |
| manager's own open rows | preparation, not trivia — collect them all |
| praise landed by name | note it, with the words |
| a figure only in the manager's head | does not exist; compute current versus plan and show the operands — points, never percent |

## Table 2 — call table (apply to each draft item, in the draft's own order)

| Call | Test | Slot |
|---|---|---|
| Recognition | written praise exists — a note, a thanks, work named | first; quoted, words and figure |
| Blocked | another desk holds it — approval not given, dependency gone quiet | early; the manager leaves with a move. Reaching wider than the draft's label — teams queued, an exec copied — say so and climb it, whatever priority was written |
| Coaching | one behaviour on two or more separate dated occasions, or a goal the report chose | middle; questions, never lectures |
| Career | the report themselves raised growth, a course, scope, review timing | middle; sincere question, keepable promise |
| Status | nothing to repair, praise or settle | last; a line or two |
| Parked | another room's business — pay, HR, a dispute a different team owns, next quarter | off the page; routed with a line why. Personal matters: "the personal matter", elaborated never |

## Table 3 — correction rules

| Draft says | Record actually shows | Call |
|---|---|---|
| "tone problem" | frustration tracing to another desk's hold-up | Blocked — the hold-up talking, not Coaching |
| "a pattern" | several messages on one problem | one issue — Coaching wants separate dated occasions |
| an impression | nothing underneath it | dropped, signals named |
| a self-caught slip | found and fixed by the report | a quick word, never a coaching slot |
| praise | no quotable instance | no opener — a line above item one admits it |
| self-diagnosed | the report found the cause and tracks it | coach the step before it — spot it sooner — on the real figures |

## Table 4 — the reply

| Section | Contents |
|---|---|
| `## What the record says` | one numbered entry per draft item: its wording quoted; **Record:** name, place, date, row or figure; **Call:** verdict and reason — "stands" when the draft was right — or parked, dropped, merged. Then **Missed:** (owed or skipped) and **Arithmetic:** (operands shown) |
| `# 1-on-1 brief: [Report] x [Manager] — [date]` | 350–700 words. **Context:** one line. Items `**name — Call, ~N min**`, a sentence or two of things to say and ask, real names and figures. Then **Off the list** (parked or dropped, with reasons), **Before the meeting** (every open manager row, each a concrete move — cleared before the report hears an ask, above all a row an item leans on), **The reasoning** (a few lines on why the calls landed) |
| thin packet | still a page: the weighing names what is missing, the brief asks rather than asserts — what cannot be seen, the question to put, what a true answer sounds like |

A worked week run through all four tables lives in `references/pit-notes.md`. Borrow the reasoning, never the facts.

# Not a 1-on-1 prep request

When the input is minutes, a transcript, or notes of a conversation already held — whatever its label — the reply is one short note under 180 words, no weighing table:

- Name what it is: a record of a meeting already held — preparation looks forward, this looks back.
- Any open actions still alive inside it earn their follow-up — owner, action, date as recorded — in a line or two; no brief, no re-sort.
- Name what would make it preparation: this week's open items, fresh figures, anything raised since.
- Private stays private — "the personal matter", nothing more.
