# Board examples

Everything here is invented. Copy the accounting, decisions and proportions — never the people, facts, wording or figures.

## Close calls

- Four draft topics require four numbered strips with the manager's exact `filed:` text. An extra open action row becomes a fifth strip marked `filed: not on the draft`; it does not split an existing topic.
- If the log reads `DONE`, `IN PROGRESS`, `OVERDUE`, `DONE`, the arithmetic is `2 of 4 supplied rows done (50%)`. A manager-owned `DONE` still counts as done, and an overdue manager row belongs in `Pre-flight`.
- `planned to escalate` remains a plan. Ask whether it happened; do not write `escalated`.
- A report waiting in one assigned review queue is not personally blocking every team. The manager owns the routing or capacity decision.
- If the report already named why an estimate slipped, coach the earlier flag: what should have been raised before the miss, to whom and when.
- A fair objection sent through a public channel keeps its substance. One narrow channel question is the ceiling, not a coaching pattern.
- A bare draft still gets a board. A record of a meeting already held gets only the redirect.

## One worked packet

The manager is preparing for Rosa Bell, Inventory Systems Analyst. The draft says: `Credit for the dashboard rescue`; `Quick feedback: curt with Vendor Ops`; `Status on reconciliation pack`; `Check on analytics academy`.

Action rows: Rosa, dashboard incident notes, `DONE`; Rosa, supplier access matrix, `IN PROGRESS`; Manager, analytics academy nomination, `OVERDUE`; Manager, warehouse data request, `DONE`.

Signals: Maya Lin, Operations Director, wrote Monday in #ops that Rosa's dashboard caught a supplier mismatch before billing close. Tuesday Rosa told Vendor Ops in #vendor-ops: “Please stop sending incomplete extracts; three failed checks today.” Wednesday the reconciliation pack was waiting on security approval. Rosa submitted: “Can the analytics academy lead toward senior analyst?” Figures: 18 of 24 reconciliation checks passed; supplier mismatches moved from 4 last week to 7.

## The board it earns

# Strip board: Rosa Bell, Inventory Systems Analyst

**Position:** Rosa has creditable dashboard work, while reconciliation is still waiting on the security approval path and Vendor Ops' extract quality is creating avoidable checks.

**Figures:** Action items: 2 of 4 supplied rows done (50%). Reconciliation checks: 18 of 24 passed (75%). Supplier mismatches rose from 4 to 7, +3 on a base of 4.

**Missing:** no vendor SLA or extract specification was supplied; no security-queue state was supplied.

1. Cleared · dashboard rescue · ~4 min
filed: “Credit for the dashboard rescue” → cleared: Maya named the mismatch Rosa caught before billing close.
Open with Maya's message and the effect on billing close. Keep the credit tied to the dashboard rescue, not general effort.

2. Re-routed · Vendor Ops extracts · ~7 min
filed: “Quick feedback: curt with Vendor Ops” → re-routed: one justified objection about incomplete extracts, not a pattern.
Treat this as a process unblock. Confirm which fields Vendor Ops must include, agree who owns the extract spec, and ask at most one narrow question about channel if it still matters.

3. Holding · reconciliation pack · ~6 min
filed: “Status on reconciliation pack” → holding: the pack is waiting on security approval and the queue state is not supplied.
Ask which approval is outstanding, who can release it and what Rosa can complete while the pack waits. Your move is to obtain or name the approval date.

4. Cleared · analytics academy · ~9 min
filed: “Check on analytics academy” → cleared: Rosa submitted the senior-analyst path herself.
Ask which parts of the dashboard rescue and reconciliation work would evidence the next level, and what the academy should add rather than duplicate.

5. Holding · supplier access matrix · ~4 min
filed: not on the draft → holding: Rosa's access-matrix row is IN PROGRESS but no draft topic covers it.
Ask what remains in the matrix and whether it depends on the same security approval as the reconciliation pack.

**Pre-flight**
- Analytics academy nomination: OVERDUE with the manager; submit it or give Rosa the decision date before asking about her development path.
- Fetch the vendor extract specification or SLA.
- Fetch the current security-queue state for the reconciliation approval.

**Diversions**
Nothing diverted this week.

**Controller's log:** The opener is earned because Maya named the work and result. The Vendor Ops item moves out of feedback because the supplied message concerns missing extract fields, not repeated conduct. The access-matrix row stays visible as an unfiled open row. The academy gets real time because Rosa raised the path herself.

## Thin packet reminder

For only a future draft, the head says which records never arrived. Every topic still receives a numbered strip and `filed:` line; each strip states what is unknown, asks a question grounded in the manager's wording and names the missing record that would settle it.

## Held-meeting reminder

A held-meeting note starts `# <name>, <role>: not a 1-on-1 prep request`, stays under 180 words and sends no board. It lists open actions with exact owner and due date, states that current status is absent, and asks for action status, fresh signals, a report topic and a new draft agenda.
