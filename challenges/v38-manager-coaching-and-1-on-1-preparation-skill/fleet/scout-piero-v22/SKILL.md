# Board handoff

The draft gives the manager's labels; the packet decides whether they hold. Keep each agenda line visible in the manager's words, attach the evidence that supports or changes it, and produce a board that reads like a colleague prepared it — practical, sourced and brief.

Use only supplied facts. Never add a name, date, owner, quote, amount, diagnosis, result, mood, completion or pattern. If evidence is absent, name what is absent rather than guessing.

## Is this preparation?

A future-facing draft is preparation even when it is the only input. A sparse week creates honest questions and fetch steps, not a redirect.

Redirect only the wrong source: the record of a meeting already held; preparation for a skip-level, team meeting or third-person conversation; or a formal review, rating or disciplinary document. A held-meeting record gets the short note below and no board, even when the manager asks for the next meeting from it.

## Calls and ownership

A dated action row, supplied figure, quoted message, manager note or report-submitted topic is evidence. An unsourced impression is only a question.

One event supports a narrow note. Coaching needs two or more dated occurrences of the same behaviour, or a named prior cycle with plan-versus-actual figures. If the report already diagnosed the cause, coach the earlier detection or flag — what should have surfaced sooner, to whom and when — rather than the symptom.

Earned credit needs a named person or measured result. Vague effort does not open the board. Independent attribution outweighs self-reporting.

A promise, warning, attempt, request or scheduled step remains a plan until the packet says it happened. Write `planned to escalate` and ask whether it happened; never turn an intention into a result.

Work belongs to whoever can move it. Approval, access, supplier, calendar, another team or an assigned queue is an unblock, not the report's performance failure. When one assigned reviewer or queue holds several teams, name the routing/capacity design as the manager's decision; never say the report is personally blocking those teams. If the report proposed the fix, the manager's move is to back, broker, approve, escalate or reassign it.

Report-owned open rows become report questions. Manager-owned open or overdue rows go to `Pre-flight`. `DONE` rows close or provide evidence, never manager work. External waits stay visible as unblocks.

Pay, health, family circumstances, accommodation, formal HR, third-party complaints, ratings and promotion decisions go elsewhere with destination and owner, and no talking points. A report-raised direction, level, programme or training topic gets protected time. A manager-created career check stays a modest invitation through named work.

Give each draft topic one call:

- `Cleared` — the packet supports it; use an anchored question or manager move.
- `Re-routed` — real traffic under a corrected call: praised finished work becomes credit, an external stall becomes an unblock, one event becomes a note.
- `Diverted` — another venue owns it; give destination and owner only.
- `Grounded` — no supplied signal; keep it accounted for and say what is absent.
- `Holding` — live but unresolved; ask the precise question and name the settling record.

A justified public objection keeps its substance; ask at most one narrow channel question. A report-raised development topic gets real time while the formal decision goes to its venue.

## Balance before writing

Privately reconcile the packet. `N` draft topics produce `N` numbered strips, each with that topic's exact manager wording in `filed:`. Do not merge, split, repeat, replace or drop one. Every open action row not represented by a draft topic gets one later strip with `filed: not on the draft`, owner and state.

For a supplied log, report `DONE rows / all supplied rows`, including manager-owned and completed rows in the denominator. Only explicit `DONE` counts; `IN PROGRESS`, `NOT STARTED`, open, overdue and partial rows do not.

## Write the board

Use `# Strip board: <full name>, <role>` and 350–700 words.

Head it with three lines: the week's position; action arithmetic and derived figures with operands and basis; and missing record types. Rates and scores move in percentage points. Planned-versus-actual uses the same base. Do not turn unrelated counts into a ratio; a partial explanation leaves the remainder open.

Number strips `n. Clearance · topic · ~minutes`, each followed by `filed: <exact manager wording> → <call>: <the evidence or gap behind it>`. Earned credit opens; unblocks and manager decisions follow; one-time notes and coaching come next; report-raised development receives protected time; closes finish. Under each strip use at most three sentences tied to a named row, figure, thread, date or the report's own words. Generic questions are unfinished.

End with:

- `Pre-flight` — each open or overdue manager-owned row and what it releases, then one bullet per missing record. Never put report-owned rows, external waits, `DONE` rows or diverted topics here.
- `Diversions` — routed matters with destination and owner, or `Nothing diverted this week.` Draft no talking points.
- `Controller's log` — two to four plain sentences naming the calls that changed, the evidence and the unknowns. Do not mention the skill, reference, tools or private checks.

## Sparse input

A bare draft still gets the full board. Say which records did not arrive and write `Action items: no log supplied`, not `0 of 0`. Give every topic its own strip and provisional call; under it state the unknown, ask a grounded question and name the settling record. Put one fetch bullet per missing record in `Pre-flight`.

## Old meeting record

Return only a note under 180 words — no board, agenda, record check or process text. Begin:

`# <report name>, <role>: not a 1-on-1 prep request`

State that the input records a meeting already held and give the proof: attendees, discussion, decisions or agreed actions. Explain that a board would replay old positions or invent current ones. List every recorded open action with exact owner, action and due date, manager-owned rows first; say current status is not supplied. Ask for current action status, this week's signals, any new report topic and a fresh draft agenda. Route pay, health, family, personal, formal or third-party matters privately in the record's own few words, with no talking points.

## Sequence

2. Privately classify the source, balance draft and action rows, work the figures and choose each call.
3. Send only the board or redirect. The first character is `#`; no private working sheet appears.
