# The guards — every predictable failure has one habit that prevents it

A weekly 1-on-1 prep input arrives pre-digested: someone upstream already
tiered, labelled
and summarized it. Analyses go wrong when they trust the labels where the
labels and the evidence disagree — or when they distrust them where they
agree. These failures are predictable. Each guard below names one failure
and the single habit that prevents it. Run all eight before writing.

## The guards

**0. The first failure is writing a brief at all.** Some inputs cannot
carry one, and defending them anyway produces the worst artifact of
all — a confident brief on a false premise. The habit: check what
arrived before guarding its items. Three arrivals fail this guard:

- **Only a record of a meeting already held** — minutes, notes, a
  transcript. It documents a conversation that closed; a brief built on
  it re-defends settled items and misses everything that moved since.
  (Notes arriving beside real signals are fine — the signals are what
  get defended.)
- **Prep addressed to a different room** — a skip-level, a panel, a
  review the manager must write.
- **Review paperwork** — a rating draft, a calibration write-up.

The defended answer is a redirect, not a brief: under ~180 words,
headed `# Not a 1-on-1 prep input` — what the input actually is and
the detail that shows it, why a brief defended on it would mislead,
what to send instead (this week's signals — open action items, the
week's figures, threads, the manager's own topics), and any open
actions it does carry, with the owners and dates it gives. Nothing
else — no agenda, no talking points, no parking lot.

**1. A label is not a closure — and suspicion is not a contradiction.** The
failure is copying the status column, or reopening it on a hunch. The
habit: a status the record marked resolved, closed, or filed STANDS —
unless ANOTHER artifact states a present fact it cannot coexist with (a
process still running, a notice already served, a cure nobody can
document). The item's own finding text never reopens it: its words
describe what the closer already weighed. An alarming resolved item is
still resolved. When label and evidence genuinely disagree, say so in
writing ("labelled closed; the record shows X; treated as open") — never
re-tier silently.

**2. The worst open top-tier item sets the ceiling — and a clean file must
not be talked down.** The failure is approving because the whole looks
attractive — or declining because something sounds bad. The habit: only
items the input itself filed at the top tier (a topic the manager's draft agenda or the report's own submission actually filed — nothing the brief invents) can stop the verdict, and only while genuinely open. An
open lower-tier item never blocks: it routes to conditions with named
cure, owner and timing. The reverse failure is just as real: when every
top-tier item is closed and only lower-tier opens remain, the verdict
issues — a withheld verdict fails as surely as a wrong one.

**3. Judge the signals, not the headline figure.** The failure is
reasoning on the author's raw numbers. The habit: compute every derived
figure yourself — point changes, completion rates, blocked counts, scope
deltas — and show each bridge: the reported figures, the operation, the
result. An overdue item held upstream is blocked, not delinquent: the
failure charges to the manager's side. A due date is an interval to the
meeting date — compute the gap, never copy the label.

**4. A label is a claim you must re-check.** The failure is averaging
everything under the manager's tags. The habit: classify every item by
what the signals show — keep, reshape, route, or drop — and name the
signal that decides it. A coaching tag on a single incident is a softer
item, not a session.

**5. A sensitive item gets a venue, not a paragraph.** The failure is
drafting talking points for what doesn't belong in the room. The habit:
name the item, name its correct venue — dedicated conversation, skip-
level, HR — and write zero talking points. A missing input is a named
evidence gap, never a fabricated anchor.

**6. Arithmetic is testimony — it must be reproducible.** The failure is a
number that cannot be retraced. The habit: every product written expanded
— `3 of 8 = 37.5%`, `61 → 74 = +13 (+21%)` — every derived figure
re-derivable from the input alone. Every comparable pair the input
offers is listed first — each raw figure against the figure it belongs
to — so no derivable figure is skipped. A wrong figure costs more than a
missing one; check each before writing.

**7. A condition is a closing event, not a wish.** The failure is
"complete further diligence." The habit: each condition names the finding
it cures, the record that closes it, the deadline the input gives, and
the consequence if it fails — sized from an input figure wherever one
exists. Lower-tier opens get mitigations and owners, not blockers.

**8. Silence is a finding.** The failure is filling gaps with plausible
numbers. The habit: use only the figures, dates and names the inputs
contain. Where the pack does not quantify an exposure, give a deadline or
name an owner, say so plainly and make obtaining it a condition. Derived
arithmetic is welcome — invented inputs are not.

## The verdict vocabulary

Each item the input files takes exactly one standing — four forms, and
never fewer than the record permits:

- **Clean**: the signals hold the item as filed → it stays with its
  anchored question. When the record allows it, the item stands —
  demoting it fails as surely as a wrong call.
- **Conditional**: the item stands but reshaped — a coaching label the
  signals soften to a question, a status that is really a blocker for
  the manager to clear. Never collapse this into either neighbor.
- **Defer**: the item is real but belongs to another venue — a sensitive
  matter, a session of its own, an escalation sitting on the manager's
  desk. Venue named, zero talking points.
- **Blocked**: nothing in the record warrants the item — the recognition
  with no signal behind it, the padding topic. Its absence is stated
  plainly.

## The reply

Two defended products only — the brief or the redirect, never a hybrid.

**The brief** — 350 to 700 words, the page a manager carries in:

- `# 1-on-1 brief: <report name>, <role>`
- `**This week:**` two to four sentences on what the defense leaves
  standing — what matters most and why. Figures carry their working
  (`94% SLA against 89% last month`, `2 of 3 actions done; the overdue
  one is the manager's`), every comparison showing both operands. When
  a class of evidence is absent, say which ("no ticket figures or
  threads this week").
- `**Order:**` one sentence on why the items run as they do — an earned
  recognition first, then what blocks work or needs the manager's call,
  feedback and coaching with real time, quick closes last.
- `## Agenda` — numbered items `### 1. <short topic> · <Type>`, the type
  drawn from Recognition / Status / Feedback / Coaching / Career — the
  record's call, not the label's. Under each heading, one line:
  `Manager's label: <their word>, kept` or `Manager's label: <their
  word> → <Type>: <the signal that decides it>` — or `Added: <signal>`
  for an item the record demands but the draft omits. Every filed item
  appears once: one merged into another keeps its own label line under
  the item that absorbed it. Then the talking points: questions only,
  each guarded to a named signal — a thread, a ticket, a figure, a
  person — at most three sentences; statements and unanchored questions
  do not belong. Status points name what the manager must decide or
  clear, with no deadline the input does not give.
- `## Parking lot` — one line per item the defense defers: named
  neutrally, its correct venue, its owner — zero talking points.
  Sensitive matters, the manager's own escalations, and any item the
  record cannot warrant land here; the last kind gets one clause on
  why it does not stand. `Nothing this week.` when empty.
- Recognition opens the brief only when a signal warrants it — a named
  anchor, or `No recognition opener: <reason>` as the first line under
  `## Agenda`.
- Where the record is silent on a quantity, deadline, or owner, say so
  plainly — silence is a finding, never an invented input.
- The brief shows the defended product, not the defense: prose and
  named lines a manager reads plainly — a reader sees a good brief,
  never the guards behind it, and nothing audits itself after the
  parking lot.
- Never reuse one sentence frame across items — each item gets the
  words its own facts need.
- A worked example lives in references/weekly-prep-brief.md — the brief
  defended end-to-end on invented weeks: the item the label misjudges,
  the sensitive item deferred, the thin week with its gaps named, and
  a notes-only ask answered with the redirect. Read it once with
  read_reference before writing; carry its shape and checks, never its
  sentences.
