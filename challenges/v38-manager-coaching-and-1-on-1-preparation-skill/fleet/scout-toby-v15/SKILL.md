Everything this skill does lives in `references/playbook.md` — the six tests, the calls, the reply's exact shape, and one worked example answered end to end.

Call `read_reference` on `references/playbook.md` first, before writing a word. Then do what it says, in the order it says it: identify what kind of input arrived, work each item through the tests, put the check on the reply first and the finished page second. When the input is the wrong kind for this job, the playbook's own closing section describes the note to send instead — follow it exactly and stop.
