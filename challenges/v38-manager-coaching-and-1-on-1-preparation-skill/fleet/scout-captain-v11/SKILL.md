# The evidence pass

Weekly 1-on-1s fail upstream, in a draft agenda written from memory. Memory keeps topics and loses proof: a stall only the manager can clear gets filed as "status", one bad day as "coaching", somebody's thanks as "a shoutout". The rules below force the evidence to sort each draft item on the page, above the brief, so the manager sees which signal moved which label. Notes or minutes of a meeting already held are not prep — every status inside is a week old; they get a short reply note, never a brief. Same for review drafts and skip-level asks. A bare draft still gets a page, built of questions rather than claims.

## Rules of the pass

1. Read the packet once before the draft: every action row with owner and status word (manager rows count), every figure beside its comparator, every message with author and rough time, every topic the report raised.
2. Work every sum first: change vs baseline = (now − before) / before, signed whole percent (3 closed on a trailing 8 = −63%); estimate vs actual or grown scope uses the same sum (3 days planned, 5 spent = +67%; 20 screens grown to 26 = +30%); rates move in points (CSAT 72% → 80% = +8 points); completion counts only "done" rows — in progress, overdue, NOT STARTED are open, manager rows included; a cause covering part of a gap leaves the rest open (30% explained → 70% to ask about).
3. Missing inputs are named and asked for, never invented: no figures, dates, moods or quotes from thin air. Disagreeing inputs are named as disagreeing.
4. Class each draft item from evidence alone — the draft's label and priority are proposals, not facts.

## The six calls

| Call | Evidence test | What it does in the meeting | Minutes |
|---|---|---|---|
| Credit | a signal names the work — quotable line with where/when, a ship, a moved figure | opens the page, quoted; specific lands, vague is filler; praised finished work goes here whatever the draft said; no signal, no opener | 3–5 |
| Stall | held up by somebody else — missing approval, silent dependency, overload, waiting teams | manager's own move ends it; sharp messages after ignored chases are the stall, not tone | 5–10 |
| Nudge | one slip, usually owned | name it, agree the fix, check what it left open; never inflate an owned slip into a theme | 2–4 |
| Habit | same behaviour in ≥2 situations, or a goal the report set | questions, not lectures; a contradicted impression ("disengaged" vs early flags, picked-up work) is dropped with signals named; if the report already found the cause and tracks it, coach the step before — flag changes sooner — anchored to figures, not the symptom | 10–15 |
| Ambition | report's own question on level, scope, direction, or a programme | real time tied to this week's best work; if a packet or calibration decides, the next step stays and the decision is set aside; a pencilled check-in is one open question, marked theirs | 8–12 |
| Loose end | open work whose state the input does not show | never done or approved work | 2–3 |

Minute ranges are defaults — a packed page gives the biggest class the room and trims updates first.

Off-page topics — pay, health or family, colleague complaints, promotion decisions, process talks an outsider asked for — are set aside with venue and arranger, no talking points; sensitive ones are named by request alone.

## Traps the draft sets

- **A mislabeled stall.** The draft says "check in on X" but the rows show the block sits with the manager or another team — it goes in as Stall with the manager's move, never as a status pep-talk.
- **An owned slip dressed as coaching.** One corrected mistake is a Nudge. Two or more separate situations make a Habit — and if the report already named the cause and tracks it, the coaching target is the step before it.
- **A quiet manager row.** The manager's own overdue or NOT STARTED row is never left off the page because the draft forgot it — `Off the draft` catches it and `Your rows` carries it.
- **A compliment that never landed.** Praise sitting in a channel is Credit even if the draft buried it under updates — quoted, with the figure beside it.
- **A private thread.** Health, family or pay appearing anywhere is set aside by request name only; the page never carries the reason.

## The page

`## Over the draft` first, then `# Weekly 1-on-1:` — nothing before them.

Over the draft, in order:

- one line: is this prep, and why;
- one line per draft item, in the draft's order: `N. "label" → **Call** — grounds (who said or logged what, where, when, with row or figure) and the reason`, or `→ label holds` / `→ set aside` / `→ dropped` / `→ folded into N`;
- `**Off the draft:**` owed or missed items — the manager's own rows, an un-agenda'd block, a request needing routing;
- `**The sums:**` rows named and counted, then every figure pair with both inputs.

A thin week replaces item rows with three or four sentences: what arrived, what did not, what each label would need to be testable.

The brief: name and role on the title line; a two-to-three-sentence header — hardest finding first with cause and next-move owner, the week's load-bearing figures, "Action items: X of Y done (Z%)". Items in meeting order — earned credit; stalls and whatever holds others; the report's own topic; nudge or habit; ambition; loose ends — each headed `**N. <item in this week's words> - <Call>**`, three sentences max: signal, your move, and for habit or ambition a question naming a thread, ticket or their own words. "What made the Tuesday date feel fixed?" fits one person; "How can I support you?" fits anyone. Address the manager as "you"; their words in quotes. Set-aside or dropped items get no number.

Then `**Set aside**` (topic, venue, arranger — or "Nothing this week."), `**Your rows**` (owed rows only, never done ones, plus inputs to pull; omit when empty) and `**How this was sorted**` — three to five plain sentences: moved labels and their signals, held labels, why there is or is not an opener, why anything left. Total 350–700 words; a thin week is all questions, no opener, no coaching.

## Old minutes

Notes, minutes or transcript of a meeting already held — date, attendees, agreed actions — record a finished conversation even when the manager asks to prep the next one from them. The entire reply is one note under 180 words titled `# A record, not a request`, no sorting section: what the paste is and its give-away detail, why a brief on it replays stale news, the follow-up it does support (actions with owners and dates as written), what to send instead. Anything personal is "the personal matter", nothing more.

## A worked week (invented — borrow the method, never the facts)

## Over the draft
Prep: this week's rows, counts and messages, for a meeting still to come.
1. "Status: delivery van" → **Stall** — off the road since the 4th; garage has not sent the estimate, chased 4th, 8th, 11th; hire approval is your row, overdue; none of it is Ravi's to move.
2. "Nice work on the window display?" → **Credit** — area manager's Monday note credits his layout, quarter-best footfall; quote that note.
3. "Coaching: careless till receipts" → **Nudge** — one misfiled batch Friday, corrected and flagged same day, nothing earlier; one owned slip is no habit.
4. "His question about the evening course" → **Ambition** — label holds; his Wednesday message asks it.
5. "Staff discount" → **set aside** — a pay question in his note; pay desk with payroll.
**Off the draft:** the hire approval you owe.
**The sums:** van open, window report done, hire approval overdue — 1 of 3 done (33%); 1,240 visitors on a trailing 980 = +27%.

# Weekly 1-on-1: Ravi Okafor, shop-floor lead
The delivery van has been off the road since the 4th waiting on an estimate the garage has not sent; the hire approval that forces a date is yours. The window display drew the quarter's best footfall, up 27%. Action items: 1 of 3 done (33%).

**1. The window display - Credit**
Read Ravi the area manager's line about his layout, with the footfall figure beside it.

**2. The delivery van - Stall**
Three chases went unanswered, so this is yours. Say when the hire approval will be signed, then ask which deliveries are exposed.

**3. The evening course - Ambition**
Running the window end-to-end was lead work. "Which part of that week would you want as your job?"

**4. The misfiled receipts - Nudge**
Corrected and flagged the same day. Agree his end-of-shift check.

**Set aside**
- **Staff discount**: pay desk with payroll; you set it up this week.

**Your rows**
Sign the hire approval you owe; item 2 hangs on it.

**How this was sorted**
The van moved from status to stall: three unanswered chases and your overdue approval hold it. The thanks became credit once the note named the work; one misfiled batch put right the same day is a nudge. Ambition held because he asked; the discount question is pay, so it left the page.

# A record, not a request
What you sent is the record of last Tuesday's 1-on-1 with Ravi: attendees, discussion, actions agreed. A brief built from it would replay that meeting as news. It supports a follow-up on its actions: the hire approval (you, by the 15th) and the spring rota (Ravi, by the 18th). For next week's page, send where each stands now, this week's counts or messages, and your draft. The personal matter stays private.
